- Headings
- Tables
- Bullet lists

# Technical Documents

Technical documents should explain:

- What

- How
- Advantages
- Disadvantages

# Interview Philosophy

Questions should become progressively deeper.

Example

Basic

"What is Redis?"

↓

Intermediate

"Why Redis instead of Local Cache?"

↓

Advanced

"How do you solve cache consistency?"

↓

Expert

"What problems occurred in production?"

↓

Architect

"What would you improve?"

Always think like a Senior Interviewer.

---
