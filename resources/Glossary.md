## Overview

## Useful Answer Expressions

| Expression | Usage |
|---|---|
| 〜と考えています | 부드러운 의견 표현 |
| 〜を意識しています | 실무에서 중요하게 생각하는 점 |
| 〜に取り組みました | 수행 경험 |
| 〜に貢献しました | 기여 표현 |
| 一方で | 단점이나 주의점 전환 |
| そのため | 이유와 결론 연결 |
