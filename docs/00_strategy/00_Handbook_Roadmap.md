# Japan Backend Engineer Handbook Roadmap

## Overview

이 문서는 `Japan Backend Engineer Handbook`의 최종 목표와 작성 순서를 정의한다.

목표는 단순한 예상 질문 모음이 아니라, 일본 프로덕트 회사 면접에서 사용할 수 있는 **기술・경험・일본어 답변・꼬리질문 대응 체계**를 구축하는 것이다.

## Writing Priority

1. 실제 이력서 기반 답변을 먼저 만든다.
2. 일본어 면접에서 말할 수 있는 길이로 작성한다.
3. 기술 질문은 Basic → Intermediate → Advanced → Expert 순서로 깊어진다.
4. 모든 답변은 실제 프로젝트 경험과 연결한다.
5. AI 경험은 마케팅처럼 쓰지 않고, 개발 프로세스 개선 경험으로 설명한다.

---

## Quality Rules

- 얕은 설명보다 면접에서 말할 수 있는 답변을 우선한다.
- 일본어 답변은 자연스럽고 겸손한 비즈니스 표현을 사용한다.
- 한국어 해설은 답변 의도와 보완 포인트를 설명한다.
- 꼬리질문은 면접관 관점에서 날카롭게 작성한다.
- 모든 문서는 다른 문서로 확장될 수 있어야 한다.
