# 이직 이유

## 목적

이 문서는 면접에서 자주 나오는 **“이직하려는 이유는 무엇인가요?”**에 대한 한국어 원본 답변을 정리한다.

핵심은 현재 회사를 부정하지 않으면서도, **AI를 더 적극적으로 활용할 수 있는 환경에서 성장하고 싶다**는 방향을 분명하게 말하는 것이다.

---

## 답변 방향

| 순서 | 말할 내용 | 의도 |
|---|---|---|
| 1 | 제가 이직을 결심한 가장 큰 이유는... | 답변의 시작을 명확히 한다 |
| 2 | 고객사 프로젝트로 다양한 도메인 경험을 쌓았다 | 현재 회사 경험을 짧게 긍정한다 |
| 3 | 파견 프로젝트 중심이라 AI 활용 기회가 많지 않았다 | 현실적인 이직 이유 |
| 4 | HRMS와 Tokyo-Sane에서 AI 활용 가능성을 체감했다 | 변화의 계기 |
| 5 | AI를 개발 프로세스에 더 적극적으로 활용하고 싶다 | 다음 목표 |
| 6 | 팀과 서비스의 품질, 생산성 향상에 기여하고 싶다 | 회사 입장에서의 가치 |

---

## 그대로 암기할 이직 이유

실제 면접에서 이 흐름을 그대로 말한다.

```text
제가 이직을 결심한 가장 큰 이유는, AI를 더 적극적으로 활용하면서 개발 품질과 생산성을 높이는 일에 도전하고 싶기 때문입니다.

현재 회사에서는 고객사 프로젝트를 통해 다양한 도메인의 업무 시스템 개발 경험을 쌓았습니다.
다만 고객사 파견 프로젝트가 중심이다 보니, 현장 규칙이나 보안상의 제약으로 실제 업무에서 AI를 본격적으로 활용할 기회는 많지 않았습니다.

그런 상황에서 사내 HRMS 프로젝트와 개인 프로젝트 Tokyo-Sane을 진행하며, 요구사항 정리부터 설계, 구현, 리뷰, 테스트까지 AI를 활용해보았습니다.
그 경험을 통해 AI는 단순히 코드를 빨리 작성하는 도구가 아니라, 개발 프로세스 전체의 품질과 재현성을 높이는 도구라고 느꼈습니다.

앞으로는 지금까지 쌓아온 Java와 업무 시스템 개발 경험을 기반으로, AI를 더 적극적으로 개발 프로세스에 활용하며 팀과 서비스의 품질, 생산성 향상에 기여하고 싶어 이직을 결심했습니다.
```

## 짧게 말해야 할 때

```text
제가 이직을 결심한 이유는, AI를 더 적극적으로 활용하면서 개발 품질과 생산성을 높이는 일에 도전하고 싶기 때문입니다.

현재 회사에서는 고객사 프로젝트를 통해 다양한 도메인의 업무 시스템 개발 경험을 쌓았습니다.
다만 고객사 파견 프로젝트가 중심이다 보니, 실제 업무에서 AI를 본격적으로 활용할 기회는 많지 않았습니다.

HRMS와 Tokyo-Sane 프로젝트를 통해 AI가 개발 프로세스 개선에 도움이 될 수 있다고 느꼈고, 앞으로는 Java 개발 경험과 AI 활용 경험을 함께 살릴 수 있는 환경에서 성장하고 싶습니다.
```

## 일본어 버전

```text
私が転職を決意した一番大きな理由は、AIをより積極的に活用しながら、開発品質と生産性を高めることに挑戦したいと考えたためです。

現在の会社では、顧客先プロジェクトを通じて、さまざまなドメインの業務システム開発経験を積んできました。
一方で、顧客先常駐のプロジェクトが中心であるため、現場のルールやセキュリティ上の制約により、実務の中でAIを本格的に活用する機会は多くありませんでした。

そのような中で、社内HRMSプロジェクトや個人プロジェクトのTokyo-Saneを進める中で、要件整理から設計、実装、レビュー、テストまでAIを活用してみました。
その経験を通じて、AIは単にコードを早く書くための道具ではなく、開発プロセス全体の品質や再現性を高めるための道具だと感じました。

今後は、これまで培ってきたJavaと業務システム開発の経験を基盤に、AIをより積極的に開発プロセスへ活用し、チームやサービスの品質、生産性向上に貢献したいと考え、転職を決意しました。
```

## 피해야 할 표현

- 현재 회사에서는 배울 것이 없다.
- 파견은 한계가 많다.
- AI를 못 쓰게 해서 이직한다.
- AI를 많이 쓰는 회사라면 어디든 좋다.

```text
HRMS/Tokyo-Sane으로 가능성 체감
Java 경험 + AI 활용으로 품질/생산성 기여
```
